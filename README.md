
# Sydney's Developer Portfolio

A personal portfolio website built with React to showcase my background, skills, education, and software development projects.

## Technologies

- React
- JavaScript
- HTML
- CSS

## Running Locally

1. Navigate to the React application folder:

   ```bash
   cd portfolio
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm start
   ```

The website will open locally in your browser.
